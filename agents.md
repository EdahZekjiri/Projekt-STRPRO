
## Project Overview

This project is a Java based text adventure game. (Created with the help of AI of course)

## General Instructions

1. Use Java as the programming language.
2. Keep the code beginner-friendly.
3. Separate different game mechanics into classes.
4. Avoid unnecessary external libraries.
5. Explain major changes before implementing them.
6. Do not remove existing features without permission.
7. Ensure the application runs in IntelliJ IDEA.

## Code Quality

- Follow Java naming conventions.
- Avoid duplicated code.
- Handle invalid user input, for example, if scanner demands an integer and the user inserts a double. 
- Keep methods short and understandable.

## Testing

- Test all available player choices.
- Verify combat calculations.
- Ensure the game does not crash on invalid input.
