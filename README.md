# The Forgotten Kingdom

Author: Edah Zekjiri

## Project Description

The Forgotten Kingdom is a text-based adventure game
developed in Java.

The player explores a mysterious fantasy world,
makes decisions, fights enemies and completes quests.

The story changes depending on the player's decisions.

Whenever a decision is made, algorithms decide based on the current player stats, how the story continues.

## Technologies

- Java
- IntelliJ IDEA
- GitHub
- Github Copilot
- Git

## How to Run

1. Open the project in IntelliJ IDEA.
2. Run Main.java.
3. Follow the instructions in the console.
